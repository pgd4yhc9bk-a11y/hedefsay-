# İndirilen dosyalar

Karakter modelleri ve animasyon dosyalarını bu klasöre yükle:

1. GitHub'da bu klasörü aç (`oyun-fikirlerim/iki-kisilik-oyun/indirilenler/`)
2. **Add file → Upload files**
3. Dosyaları sürükle, **Commit changes**

Gerekenler (Quaternius, CC0):
- Universal Base Characters → genç kız ve genç erkek modelleri (glTF/GLB + dokular)
- Universal Animation Library → glTF/GLB dosyası

Tek dosya sınırı 25 MB. Daha büyükse sohbete gönder ya da zip'i parçala.
